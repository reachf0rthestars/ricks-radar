# Rick's Radar Docs (Docusaurus)

This site renders developer documentation for Rick's Radar.

## Local commands
- `npm.cmd install`
- `npm.cmd start`
- `npm.cmd run build`
- `npm.cmd run serve`

## Deployment
- Branch: `docs`
- Workflow: `.github/workflows/docs-hosting-deploy.yml`
- Firebase site: `ricksradar-dev-docs`

## Notes
- Keep documentation content in `docs/`.
- Follow `docs/documentation-playbook.md` and `docs/docs-audit-checklist.md` before merges.
