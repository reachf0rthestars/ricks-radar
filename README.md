# Ricks Radar
Ricks Radar is hosted on Firebase. It can be accessed at [RicksRadar.web.app](https://ricksradar.web.app)
Devloper Documentation can be found on at [RicksRadar-Dev-Docs.web.app](https://ricksradar-dev-docs.web.app)

## Notes
When branches are merged into Main, they are automatically deployed to Firebase. 
When adding things into the Docusaurus inside of the `docs` folder, they'll automatically be deployed to RicksRadar Dev Docs.
